## CoS 판단 (2026-10-13)

- A안 "토익 800, 시험일까지 계획부터 세우세요."는 사용자가 정한 목표를 가리키는 문장이고 결과를 약속하지 않으므로 점수 보장 표현으로 보지 않는다. 다만 하위 문구에 "목표 점수는 사용자가 정한 값이며 결과를 보장하지 않습니다"를 함께 둔다.
- 무료 조건 문구 크기는 실제 페이지 구현 때 버튼 글자 크기 이상으로 맞춘다.
